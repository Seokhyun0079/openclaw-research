청구서 엑셀 자동화 진행 계획

목표

청구서용 엑셀 템플릿을 정해 두고, 이름·주소·금액·공수 등만 알려주면 스크립트가 청구서를 만들고, 나중에는 메일로도 보낼 수 있게 한다.

현재 상태 (2026-08-04)

  • 가능: 빈 엑셀 템플릿 생성 + 입력값 채우기 (bin/oc-make-invoice)
  • 가능: Google Chat에서 사용자가 파일을 첨부하면 ~/.openclaw/media/inbound/로 수신
  • 불가: Google Chat으로 결과 파일 첨부 발송 (서비스 계정 업로드 권한 없음)
  • 불가: 메일 발송 (SMTP/Gmail API 등 미설정)

전체 흐름

  1. 템플릿 엑셀 확정 (레이아웃·항목)
  2. 채팅/CLI로 입력값 전달
  3. 스크립트가 청구서_이름_날짜.xlsx 생성
  4. (선택) PDF 변환
  5. (선택) 메일 발송 또는 iMessage 등으로 전달

단계별 계획

Phase 1 — 엑셀 생성 (진행 중 / 초안 완료)

  • 빈 템플릿: templates/invoice-blank.xlsx
  • CLI: oc-make-invoice --name --address --amount --hours
  • 출력: state/invoices/
  • 기본 항목: 이름, 주소, 금액, 공수, 작성일

다음 할 일

  • 실제 쓰는 청구서 양식에 맞게 셀 배치·문구(한/일) 조정
  • 필요 시 항목 추가 (세금, 기간, 건명, 계좌 등)
  • Google Chat에서 “이름·주소·금액·공수”만 말해도 스크립트 실행되게 연결

Phase 2 — 입력 UX

  • 채팅 한 줄/여러 줄 파싱 (예: 이름=…, 주소=…, 금액=…, 공수=…)
  • 또는 사용자가 엑셀/CSV 첨부 → inbound에서 읽어 일괄 생성
  • 생성 후 로컬 경로를 채팅에 텍스트로 회신

Phase 3 — 결과물 전달

Google Chat 파일 첨부가 안 되므로 아래 중 선택:

  1. 로컬 경로 안내 (당장 가능)
  2. iMessage로 파일 전송 (oc-send / 파일 전송 확장)
  3. 메일 첨부 발송 (Phase 4)

Phase 4 — 메일 발송 (미착수)

현재 OpenClaw에 메일 채널·SMTP·Gmail 권한이 없다. 연결 후보:

  • Gmail SMTP (앱 비밀번호)
  • Gmail API (OAuth)
  • SendGrid / AWS SES

작업 순서

  1. 발신 계정·수신 기본 주소 결정
  2. 자격증명 저장 (secrets, git 제외)
  3. oc-send-mail 같은 스크립트 추가 (제목/본문/첨부)
  4. 청구서 생성 후 옵션으로 --email to@example.com 연동
  5. 외부 발송이므로 실행 전 확인 규칙 유지 (AGENTS.md)

파일 위치

  • 템플릿: ~/.openclaw/workspace/templates/invoice-blank.xlsx
  • 출력: ~/.openclaw/workspace/state/invoices/
  • 문서: ~/.openclaw/workspace/docs/INVOICE-SCRIPT.md

추천 진행 순서

  1. 템플릿 레이아웃을 실제 청구서 느낌으로 다듬기
  2. 채팅 → 스크립트 실행 연결 (수동 CLI 없이)
  3. 결과 전달 방식 결정 (경로 / iMessage / 메일)
  4. 메일 권한 세팅 후 첨부 발송 자동화

결정이 필요한 것

  • 청구서 언어·양식 (한국어 / 일본어 / 둘 다)
  • 추가 필드 (세금, 건명, 지급 기한, 계좌 등)
  • 결과 전달 채널 우선순위
  • 메일 쓸 경우 발신 계정
